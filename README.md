# БАЗ

Вечіркова гра «вгадай мелодію» — але замість радіохітів грає плейліст одного з гравців.

Компанія 3–8 людей грає в одній кімнаті: один телефон відтворює звук вголос (ведучий), решта — «баззери». Ведучий приносить свій плейліст з YouTube Music, грає короткий фрагмент випадкового треку, і хто перший тисне БАЗ — вгадує виконавця/назву. Ведучий міняється між раундами.

Мета — не сам факт вгадування, а супутній ефект: реакція компанії на музичний смак одне одного.

## Стек

- Мобільний веб, mobile-first
- Джерело музики та відтворення: YouTube Data API v3 + YouTube IFrame Player API
- Реалтайм-кімнати: WebSocket (код кімнати, приєднання через інтернет)
