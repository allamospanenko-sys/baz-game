# Concept

Ранні концептуальні напрямки: структура ігрового флоу, варіанти подачі "моменту БАЗ", тон і voice. Місце для чернеток і розгалужень до того, як вони застигнуть у wireframes.

## Флоу сесії (перша чернетка, 2026-09-03)

Джерело — опис флоу від автора продукту. Формальні рішення (скоринг, довжина раунду) вже зафіксовані в [CLAUDE.md](../CLAUDE.md); тут — сирі UX-ідеї навколо цього флоу, ще не застиглі у wireframes.

1. **Приєднання — "трясни телефоном".** Гравець відкриває лінк кімнати → трясе телефон → коротка анімація підтвердження → з'являється у списку учасників. Фізичний жест замість "тицяти кнопку" — краще пасує до вечіркового, трохи іронічного тону БАЗ.
2. **Вибір ведучого** — рандомно зі списку учасників, які потрясли.
3. **"Now playing" на екрані ведучого — референс Instagram Stories.** Коли грає фрагмент, текст (назва/виконавець на кінець раунду, чи просто хвиля-анімація під час гри — уточнити) з'являється в такт треку, як музичний стікер у сторіс: рухома типографіка, а не статичний текст. Це задає тон "не корпоративний квіз, а щось із соцмереж, яке ти й так знаєш, як юзати".
4. **Момент БАЗ.** У гравця — велика кнопка на весь екран. У ведучого — миттєвий live-індикатор "хто зараз відповідає" (ім'я + фото/аватар?).
5. **Результат раунду.** Ведучий підтверджує відповідь вголос → бали (1 за виконавця, +1 за назву) з'являються з якоюсь короткою feedback-анімацією (потрібно вирішити: святкова для правильної, м'яка/без сорому для неправильної — тон "легко, без драми").
6. **Кінець раунду (15 треків) → пропозиція "зіграти ще".** Якщо так — усі знову трясуть телефон, новий ведучий.

### Відкрито (не вирішено на рівні концепту)

- Що саме показує "now playing" анімація ведучому під час гри — сам факт, що грає музика (без підказки відповіді), чи щось інше? Відповідь ведучий бачить окремо, до чи після фрагменту?
- Як виглядає live-індикатор "хто зараз відповідає" — просто ім'я, чи щось смішніше/у тоні БАЗ (мем-реакція, звук)?
- Feedback-анімація на неправильну відповідь — як не зробити цей момент незручним для гравця перед усією компанією.
